TicketTak is a two-host Active Directory chain from Kenolab built around Kerberos ticket abuse. I’ll start with a web-based availability checker that fetches internal URLs, one of which has no DNS record. Any domain user can write to ADIDNS, so I’ll claim that name, point it at my host, and relay the machine account’s HTTP authentication to LDAP to write shadow credentials onto the computer object. From there a PKINIT certificate gets me a TGT for the machine account, and S4U2self turns that into a ticket for administrator on the host itself. On that box is an Ansible inventory with a vault-encrypted password that cracks to a domain user, who can read an IT share holding a previous pentest report. The report pastes the krbtgt AES key, so I’ll forge a golden ticket for the domain.

WEB01

Strategy

We can point git.kenocorp.lan to our host (ADIDNS) and trigger a check, so WEB01 authenticates to us over HTTP as the machine account. Then we can relay that authentication to LDAP on the DC. A computer object can write its own msDS-KeyCredentialLink, so the relay can plant shadow credentials on WEB01$. Finally, we can use the resulting certificate for PKINIT to get a TGT as WEB01$, then use S4U2self to get a ticket for administrator on WEB01.
