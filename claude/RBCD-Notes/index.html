Abusing Resource-Based Constrained Delegation

Notes on how to abuse Resource-Based Constrained Delegation (RBCD) and SPN-less RBCD from linux

  • SPN-less RBCD
    1. Normal RBCD
    2. Obtain a TGT through overpass-the-hash to use RC4
    3. Obtain the TGT session key
    4. Change the controlledaccountwithoutSPN’s NT hash with the TGT session key
    5. Obtain the delegated service ticket through S4U2self+U2U, followed by S4U2proxy
